# API Error Docs

Comprehensive documentation for API errors following [RFC 9457 Problem Details](https://datatracker.ietf.org/doc/html/rfc9457) standard. This repository contains user-friendly error pages that explain common API errors when interacting with The Marketing Pod's services.

## Error Types Covered

- Authentication errors
- Authorization errors
- Internal server errors
- Payload size limits
- Rate limiting
- Service bus errors
- Validation errors

Visit the [live documentation](https://themarketingpod.github.io/api-error-docs/) to browse all error explanations.
