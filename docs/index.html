API Error Documentation

RFC 9457 Compliant Error Responses

This API follows RFC 9457 - Problem Details for HTTP APIs for structured, machine-readable error responses.

Error type URIs serve as unique identifiers for programmatic error handling. Use the type field to identify and handle different error categories in your code.

Error Types

  • 400 Bad Request
    Validation Error
    The request body contains one or more validation errors.
  • 401 Unauthorized
    Authentication Error
    The request must include a valid Bearer token in the Authorization header.
  • 401 Unauthorized
    HubSpot Authentication Error
    The request must include a valid HubSpot signature header.
  • 403 Forbidden
    Authorization Error
    The token does not have the required 'Access.API' role to access this resource.
  • 413 Payload Too Large
    Payload Too Large
    The request body exceeds the maximum allowed size of 1MB.
  • 429 Too Many Requests
    Rate Limit Error
    Rate limit exceeded. Maximum 10,000 requests per minute per IP address.
  • 503 Service Unavailable
    Service Bus Error
    Failed to queue the event for processing. The event was not persisted.
  • 500 Internal Server Error
    Internal Server Error
    An unexpected error occurred while processing the request.
